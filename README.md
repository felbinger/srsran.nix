# rat.nix/srsRAN.nix

This module allows the declarative configuration of srsRAN in NixOS.

A custom option search for the module can be found on [rat-nix.github.io/srsran.nix](https://rat-nix.github.io/srsran.nix/)
or as 3rd-party Flake on [search.nixos.org](https://search.nixos.org/flakes?type=options&query=services.srsran).

This project is in an early stage of development!
